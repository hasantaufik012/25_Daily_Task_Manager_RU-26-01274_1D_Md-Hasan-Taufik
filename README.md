# 25_Daily_Task_Manager_RU-26-01274_1D_Md-Hasan-Taufik
Daily Task Manager is a Python 3 console app that lets users add tasks with a title, priority (High/Medium/Low) and due date (YYYY-MM-DD), view them by priority, list pending tasks and mark tasks as done. Built with lists, dictionaries, functions and file handling; tasks are saved in tasks.txt.
